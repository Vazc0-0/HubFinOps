# Versões anteriores de Logic Apps (fictícias)

Usadas por `python tools/comparar_logicapp.py exemplo` para mostrar a comparação de versões.

- `lgc-desvios-processo.v1.json`: a versão de antes de 15/09, com a recorrência **a cada 1 hora**.
  A versão atual (`logicapps/exemplos/lgc-desvios-processo.json`) roda **a cada 5 minutos**: é a mudança
  por trás da anomalia A4 dos dados de custo (mudança de patamar desde 15/09).

Esta pasta não entra na documentação gerada (`docs/logicapps/`): só as versões atuais são documentadas.
Versões reais baixadas do Azure ficam em `relatorios/azure/versoes/` (fora do Git).
